# Internal notes

Working notes between the team and their AI coding tools. Not part of the product.

What is here: the master brief and every update prompt pasted into the coding terminal, the
report each session ended with, the two review passes, the kill tests, the context ledger, the
build log, the depth map, the team pack, the recruiting messages and the day plans. They are kept
because hard rule 15 says small honest commits and no rewriting of history, and because a judge
who wants to see how the thing was built can read them in order.

What is not here: anything a user or a city reads. The product documentation stays in `docs/`.
